Главное правило

Не копируйте старый файл конфигурации поверх нового. В каждом пакете лежит свой appsettings.json и appsettings.ProdWin.json или appsettings.ProdLinux.json с актуальными ключами — переносите в него только свои значения: подключения к БД, RabbitMQ, адреса, пароли.

Колонка «В какой версии»: 1.26.7 LTS — изменение есть в 1.26.7 LTS, но не в 1.25.7 LTS; 1.26.9 — есть в 1.26.9, но не в 1.26.7 LTS; только LTS — есть в последних патчах LTS, но нет в 1.26.9.0.

Агент при автообновлении

AgentUpdater переносит в новый конфиг агента только фиксированный список ключей (таблица — в Порядке обновления). Новые параметры агента после автообновления получают значения по умолчанию.

Устаревшее, но ещё в коде

  • Orchestrator:DownloadRpaProject в конфиге агента помечен [Obsolete].
  • ConnectionStrings:* для PostgreSQL работают, если не задана секция DbConnection:Items. Для MS SQL используются только они.
  • Secrets:External=true читается с предупреждением «Secrets:External bool type is obsolete».

Что дальше

Порядок обновленияпошагово для Windows, Linux и Docker

Параметры из таблицы «Есть в LTS, но нет в 1.26.9.0»: будут ли они в следующих патчах 1.26.9.x — уточнить у разработки. TokenVersion уже есть в ветке 1.26.11.

Расхождение со старыми доками: UseExternalClient и rdpclientexternalsettings.json («Внешняя поддержка RDP-сессии») не встречаются ни в 1.25.7 LTS, ни в 1.26.7 LTS, ни в 1.26.9 — уточнить, в какой поставке они были.

Расхождение: комментарий в коде говорит, что DbStore не учитывается «при обновлении на 1.26.8.0», но в ветке releases/v1.26.8.0 он ещё читается. По коду переход — в 1.26.9, как и в старых доках.

Параметры RabbitMQ:VirtualHost, Redis:Password, Triggers:Email:UseManagedNtlm, RobotLogs:ClientTimeoutInSec, SchedulerTaskSettings:* есть уже в 1.25.7 LTS (перенесены патчами), поэтому в таблицы не вошли.

Имена очередей и обменников RabbitMQ в классах RabbitMQ служб менялись между версиями (например, AssetCacheInvalidation* в 1.25.7 и 1.26.9 против CacheInvalidation* в 1.26.7). Нужно ли что-то делать с брокером при переходе — уточнить у разработки.

Ключи Mqtt:* — необязательный режим связи WebApi и RDP2 (1.26.8–1.26.11), по умолчанию работает REST. В текущей ветке разработки проект MQTT удалён — подтвердить у разработки, в какой версии.
