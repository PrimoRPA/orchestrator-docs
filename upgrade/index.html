Обновление

Переход действующей установки на новую версию без потери лицензий и данных. Пройдите шаги по порядку — начинать с лицензии и бэкапа обязательно.

  1. Подготовиться
    1. Перед обновлением — лицензия будет действовать на новой версии, копии сделаны
    2. Изменения в конфигах — что поправить при переходе 1.25.7 LTS → 1.26.7 LTS → 1.26.9
  2. Обновить
    1. Порядок обновления — службы, агенты, роботы — для Windows, Linux и Docker
  3. Проверить
    1. Проверка установки — всё работает на новой версии

Отдельные задачи

  1. Переход с root на работу без root

    Для установок на Linux по старым руководствам, где службы работали от root.

  2. Перенос на другой сервер или СУБД

    Что перенести и что будет с лицензиями при переезде.

Частые задачи

  1. Проверить лицензию перед обновлением — чтобы она не стала невалидной
  2. Перейти с 1.25.7 LTS — что поменялось в конфигах
  3. Обновить агенты из интерфейса — дистрибутив агента и автообновление
  4. Перевести службы с root — для установок по старым руководствам

Список подобран вручную. В идеале он собирается автоматически — по популярности страниц и числу обращений в поддержку.
