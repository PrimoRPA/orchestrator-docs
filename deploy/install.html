Установка

Применимо: 1.26.9WindowsLinuxDocker

Поставьте серверную часть Оркестратора и агенты на машины роботов. Выберите один путь — Docker или службы — и пройдите его сверху вниз.

Установка в DockerВсё одним docker-compose.yml. Только PostgreSQL, без RDP2. Установка службAstra Linux, РЕД ОС, Ubuntu, Windows Server. PostgreSQL или MS SQL, RDP2 по необходимости. Машины роботов и агентАгент на каждую машину, где будут работать роботы. Нужен при любом пути.

Не знаете, что выбрать, — Выбор варианта развертывания.

В каком порядке поднимаются компоненты

Порядок одинаковый для всех путей — он задан зависимостями служб (так же они описаны в depends_on поставочного compose). В Docker его соблюдает сам compose.

  1. СУБД (PostgreSQL или MS SQL Server) и RabbitMQ. к ним можно подключиться с сервера Оркестратора по портам 5432 и 5672
  2. MachineInfo. /health на порту 5051 отвечает Healthy
  3. WebApi. При старте он применяет миграции к БД ltools, ltoolsidentity, ltoolslicense, ltoolsltwrepo. /health на порту 5001 отвечает Healthy, в журнале нет ошибок миграций
  4. Остальные службы: RobotLogs, Analytic, Notifications, States, Queues, Licenses, LogEventsWebhook, NuGet2. каждая отвечает на /health
  5. nginx с UI4 и сертификатом. UI открывается по https://<адрес>:44392
  6. RDP2 — если нужны RDP-сессии.
  7. Агенты на машинах роботов.

Порядок установки ArcSight и MCP Server и место RDP2 в последовательности в коде не заданы — уточнить. В поставочном compose RDP2 отсутствует.
