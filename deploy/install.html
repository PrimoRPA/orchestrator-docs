Установка

Применимо: 1.26.9WindowsLinuxDocker

Поставьте серверную часть Оркестратора и агенты на машины роботов. Сначала серверная часть — Docker или службы, затем агенты на машинах роботов.

  1. Серверная часть — выберите один путь
    1. Установка в Docker — всё одним docker-compose.yml, только PostgreSQL, без RDP2
    2. Установка служб — Astra Linux, РЕД ОС, Ubuntu, Windows Server
  2. Машины роботов
    1. Машины роботов и агент — агент на каждую машину, где будут работать роботы

Не знаете, что выбрать, — Выбор варианта развертывания. Дистрибутивы нужны заранее — где их взять, в Дистрибутивы.

В каком порядке поднимаются компоненты

Порядок одинаковый для всех путей — он задан зависимостями служб (так же они описаны в depends_on поставочного compose). В Docker его соблюдает сам compose.

  1. СУБД (PostgreSQL; на Windows Server можно MS SQL Server) и RabbitMQ. к ним можно подключиться с сервера Оркестратора по портам 5432 и 5672
  2. MachineInfo. /health на порту 5051 отвечает Healthy
  3. WebApi. При старте он применяет миграции к БД ltools, ltoolsidentity, ltoolslicense, ltoolsltwrepo. /health на порту 5001 отвечает Healthy, в журнале нет ошибок миграций
  4. Остальные службы: RobotLogs, Analytic, Notifications, States, Queues, Licenses, LogEventsWebhook, NuGet2. каждая отвечает на /health
  5. nginx с UI4 и сертификатом. UI открывается по https://<адрес>:44392
  6. RDP2 — обязательна, если роботы работают на Windows.
  7. Агенты на машинах роботов.
