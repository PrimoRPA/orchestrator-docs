Где лежат

Все дистрибутивы Primo RPA лежат в открытом репозитории nexus.primo-rpa.ru, вход не нужен. Релизы — в папке raw-hosted-release, LTS-версии — в raw-hosted-lts; внутри — папка с номером версии, например 1.26.9 или 1.26.7.

Папку можно открыть в браузере: релизы, LTS-версии. Любой файл скачивается и напрямую, без браузера, по адресу https://nexus.primo-rpa.ru/repository/<папка>/<версия>/<путь к файлу> — так удобно забирать файлы сразу на сервер командой curl -fsSL -O <адрес>.

Если у сервера нет доступа в интернет, скачайте архивы на компьютере с доступом и перенесите их на сервер.

Что скачать под ваш вариант

  • compose-файл;
  • конфиг nginx;
  • архив агента — для машин роботов;
  • дистрибутив робота.

Образы служб Docker скачает сам: службы Оркестратора — из реестра Primo RPA nexus.primo-rpa.ru:8000, PostgreSQL и RabbitMQ — с Docker Hub. Сертификат для стенда создаётся одной командой при установке. Агент и дистрибутив робота нужны, когда дойдёте до машин роботов; для запуска серверной части хватит первых двух пунктов.

  • архивы служб для Linux — какие именно, см. Какие службы ставить;
  • архив веб-интерфейса UI4;
  • конфиг и юниты nginx, сертификат;
  • архив агента — для машин роботов;
  • дистрибутив робота.
  • архивы служб для Windows — какие именно, см. Какие службы ставить;
  • архив веб-интерфейса UI4;
  • конфиг nginx и сертификат;
  • архив агента — для машин роботов;
  • дистрибутив робота.

Архив агента и дистрибутив робота берите под ОС машин роботов, а не сервера.
