Первый запуск

Применимо: 1.26.9WindowsLinuxDocker

Оркестратор установлен, но пока ничего не умеет: у него нет лицензии, робота и машины, на которой этот робот будет работать. На этой странице вы всё это добавите и развернёте первого робота. Запустить тестовый проект и убедиться, что всё работает, — следующий шаг, Проверка установки.

Сколько займётоколо 30 минут, плюс ожидание файла лицензии от вендора

Этап 1 из 3

Войдите и смените пароль администратора

  1. Откройте https://<адрес>:44392. В поле Тенант оставьте Тенант по умолчанию и войдите под встроенной учётной записью admin. Пароль первого входа запросите у Primo RPA, если его не передали вместе с дистрибутивом. Приветственный тур можно пропустить.
  2. Если интерфейс открылся на английском, переключите язык: кружок с инициалами справа вверху → Язык. Выбор запоминается в браузере, на другом компьютере его придётся повторить.
  3. Сразу смените пароль администратора: кружок с инициалами справа вверху → Сменить пароль. вход с новым паролем проходит
Этап 2 из 3

Получите лицензию

Без лицензии робот не запустится. Лицензию выдаёт вендор по запросу, который формирует сам Оркестратор.

  1. Откройте Настройки → Лицензии, нажмите Действия → Запрос на лицензию и заполните форму:
    • Продукт — Orchestrator;
    • Период — срок лицензии по вашему договору: месяц, три месяца, год или бессрочная;
    • Количество — 1;
    • Дата регистрации — с какого дня лицензия должна действовать.
    Нажмите Сохранить: браузер скачает файл запроса licensereq-Orchestrator.txt. появилось сообщение «Запрос на лицензию успешно сформирован», файл лежит в папке загрузок
  2. Отправьте файл запроса вашему менеджеру Primo RPA, в поддержку или на license@primo-rpa.ru — подходит любой путь. В письме напишите, что запрос создан через Оркестратор, и приложите сертификат лицензирования, который вы получили после оплаты. В ответ придёт файл *.license.
  3. Так же запросите лицензии на роботов: отдельный запрос с продуктом Robot (Enterprise) — для роботов на выделенных машинах, Robot (Desktop) — для роботов на рабочих местах пользователей. В поле Количество укажите, сколько таких лицензий вы купили: это число роботов, которые смогут работать одновременно.
  4. Когда придёт файл *.license, нажмите Действия → Добавить лицензию, выберите файл и нажмите Сохранить. Отдельно активировать лицензию не нужно. лицензия есть в списке, в колонке Состояние она действующая

Лицензия привязана к серверу, на котором создан запрос: при установке службами — к его оборудованию, в Docker — к ключу primo-machine-key из compose-файла. Если у вас тестовый и промышленный стенды, запрос нужен на каждый. Файл от тестового на промышленном не подойдёт.

Этап 3 из 3

Добавьте машину и робота

Для этого этапа нужна отдельная машина, на которой будет работать робот, с установленным агентом — см. Машины роботов и агент. Если машины пока нет, серверная часть установлена: вернитесь к этому этапу, когда машина появится.

Саму машину под робота — графическую оболочку, пользователя ОС, нужные роботу программы — готовят по инструкции робота; здесь только то, что делается в интерфейсе Оркестратора.

Порядок важен: дистрибутив робота, машина, пользователь на машине, робот. Без дистрибутива и без пользователя машины робота создать нельзя.

  1. Дистрибутив. Настройки → Система → Дистрибутивы робота → Добавить дистрибутив Робота, выберите архив zip из папки robot/ поставки. Версию, разрядность и ОС Оркестратор определит сам; первый загруженный дистрибутив сам становится дистрибутивом по умолчанию. в колонке Наличие в хранилище дистрибутив подтверждён
  2. Машина. Настройки → Система → Машины роботов → Добавить машину: имя и IP или DNS-имя. Для Linux включите переключатель Linux. в колонке Доступна появилась дата, видна Версия агента
  3. Пользователь на машине. В строке машины откройте меню ⋮ → Пользователи и добавьте пользователя: логин и пароль учётной записи ОС, под которой робот будет работать, и разрешение экрана. Для Windows это RDP-пользователь, для Linux — пользователь графического сеанса. пользователь появился в списке пользователей машины
  4. Робот. Роботы → Все роботы → Добавить робота: имя, машина и пользователь из предыдущего шага; остальные поля можно оставить как есть. После сохранения Оркестратор сам ставит робота на машину. в колонке Статус развертывания — «Выполнено»
Не видно раздела «Дистрибутивы робота»

По коду UI4 раздел показывается только в тенанте по умолчанию. Переключитесь на него.

Готово: робот развёрнут. Осталось проверить, что он выполняет проекты.

Если что-то пошло не так

С этими проблемами после установки чаще всего обращаются в поддержку:

Машина добавлена, но в колонке «Доступна» пусто

Оркестратор не достучался до агента: проверьте адрес машины, порт агента и что время на серверах совпадает. → Робот не запускается

«Нет валидной лицензии»

Лицензия не загружена, истекла или выдана на другой Оркестратор. → Проблемы с лицензией
