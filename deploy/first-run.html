Первый запуск

Применимо: 1.26.9WindowsLinuxDocker

Оркестратор установлен, но пока ничего не умеет: у него нет лицензии, робота и машины, на которой этот робот будет работать. На этой странице вы всё это добавите и развернёте первого робота. Запустить тестовый проект и убедиться, что всё работает, — следующий шаг, Проверка установки.

Этап 1 из 3

Войдите и смените пароль администратора

  1. Откройте https://<адрес>:44392 и войдите под встроенной учётной записью admin.
  2. Сразу смените пароль администратора. открылась главная страница UI4
Этап 2 из 3

Получите лицензию

Без лицензии робот не запустится. Лицензию выдаёт вендор по запросу, который формирует сам Оркестратор.

  1. Откройте Настройки → Лицензии и нажмите Запрос на лицензию. Укажите Продукт и Количество, сохраните запрос в файл и отправьте вендору. появилось сообщение «Запрос на лицензию успешно сформирован»
  2. Когда придёт файл *.license, нажмите Добавить лицензию → Файл → Загрузить. лицензия есть в списке, в колонке Состояние она действующая

Запрос привязан к конкретному Оркестратору. Если у вас тестовый и промышленный стенды, запрос нужен на каждый. Файл от тестового на промышленном не подойдёт.

Этап 3 из 3

Добавьте машину и робота

Порядок важен: сначала дистрибутив робота, потом машина, потом сам робот. Без дистрибутива UI4 не даст создать робота.

  1. Дистрибутив. Настройки → Система → Дистрибутивы робота → Добавить дистрибутив Робота. Отметьте его По умолчанию. в колонке Наличие в хранилище дистрибутив подтверждён
  2. Машина. Настройки → Система → Машины роботов → Добавить машину: имя и IP или DNS-имя. Для Linux включите переключатель Linux. в колонке Доступна появилась дата, видна Версия агента
  3. Робот. Роботы → Все роботы → Добавить робота: имя, машина и пользователь, под которым робот будет работать. сообщение «Робот успешно создан»
  4. Развертывание. У робота выберите действие Развертывание: Оркестратор сам поставит робота на машину. исчезла подсказка «Робот не развёрнут»
Машина на Linux: какой пользователь нужен

Для Windows указывается RDP-пользователь, для Linux — Пользователь графического интерфейса: под ним робот работает в графической сессии.

Не видно раздела «Дистрибутивы робота»

По коду UI4 раздел показывается только в тенанте по умолчанию. Переключитесь на него.

Готово: робот развёрнут. Осталось проверить, что он выполняет проекты.

Если что-то пошло не так

С этими проблемами после установки чаще всего обращаются в поддержку:

Машина добавлена, но в колонке «Доступна» пусто

Оркестратор не достучался до агента: проверьте адрес машины, порт агента и что время на серверах совпадает. → Робот не запускается

«Нет валидной лицензии»

Лицензия не загружена, истекла или выдана на другой Оркестратор. → Проблемы с лицензией
