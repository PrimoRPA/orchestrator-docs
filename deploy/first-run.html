Первый запуск

Применимо: 1.26.9WindowsLinuxDocker

После установки в Оркестраторе нет лицензии, машин и роботов. На странице описаны первый вход, получение лицензии, добавление машины и развёртывание первого робота. Запуск тестового проекта описан на следующем этапе — Проверка установки.

Сколько займётоколо 30 минут без учёта ожидания файла лицензии

Этап 1 из 3

Войдите и смените пароль администратора

  1. Откройте https://<адрес>:44392. В поле Тенант оставьте Тенант по умолчанию и войдите под встроенной учётной записью admin. Пароль первого входа предоставляет Primo RPA: если он не передан вместе с дистрибутивом, запросите его. Приветственный тур можно пропустить.
  2. Если интерфейс открылся на английском, переключите язык: кружок с инициалами справа вверху → Язык. Выбор сохраняется в браузере; на другом компьютере язык выбирается заново.
  3. Смените пароль администратора: кружок с инициалами справа вверху → Сменить пароль. вход с новым паролем проходит
Этап 2 из 3

Получите лицензию

Без лицензии запуск роботов невозможен. Лицензия выдаётся по файлу запроса, который формируется в Оркестраторе.

  1. Откройте Настройки → Лицензии, нажмите Действия → Запрос на лицензию и заполните форму:
    • Продукт — Orchestrator;
    • Период — срок лицензии по договору: месяц, три месяца, год или бессрочная;
    • Количество — 1;
    • Дата регистрации — дата начала действия лицензии.
    Нажмите Сохранить: браузер скачает файл запроса licensereq-Orchestrator.txt. появилось сообщение «Запрос на лицензию успешно сформирован», файл сохранён в папке загрузок
  2. Отправьте файл запроса менеджеру Primo RPA, в поддержку или на license@primo-rpa.ru. В письме укажите, что запрос сформирован в Оркестраторе, и приложите сертификат лицензирования, полученный после оплаты. В ответ направляется файл *.license.
  3. Аналогично запросите лицензии на роботов: отдельный запрос с продуктом Robot (Enterprise) — для роботов на выделенных машинах, Robot (Desktop) — для роботов на рабочих местах пользователей. В поле Количество укажите число приобретённых лицензий: оно определяет, сколько роботов могут работать одновременно.
  4. После получения файла *.license нажмите Действия → Добавить лицензию, выберите файл и нажмите Сохранить. Отдельная активация лицензии не требуется. лицензия есть в списке, в колонке Состояние она действующая

Лицензия привязана к серверу, на котором создан запрос: при установке службами — к его оборудованию, в Docker — к ключу primo-machine-key из compose-файла. Для тестового и промышленного стендов запросы формируются отдельно: лицензия одного стенда на другом недействительна.

Этап 3 из 3

Добавьте машину и робота

Для этапа требуется машина робота с установленным агентом — см. Машины роботов и агент. Если машины нет, установка серверной части на этом завершена; этап выполняется после подготовки машины.

Подготовка машины — графическая оболочка, пользователь ОС, программы, с которыми работает робот, — выполняется по инструкции робота. Ниже описаны только действия в интерфейсе Оркестратора.

Порядок действий обязателен: дистрибутив робота, машина, пользователь на машине, робот. Без дистрибутива и пользователя машины создать робота невозможно.

  1. Дистрибутив. Настройки → Система → Дистрибутивы робота → Добавить дистрибутив Робота, выберите архив zip из папки robot/ поставки. Версия, разрядность и ОС определяются автоматически; первый загруженный дистрибутив назначается дистрибутивом по умолчанию. в колонке Наличие в хранилище дистрибутив подтверждён
  2. Машина. Настройки → Система → Машины роботов → Добавить машину: имя и IP или DNS-имя. Для Linux включите переключатель Linux. в колонке Доступна появилась дата, видна Версия агента
  3. Пользователь на машине. В строке машины откройте меню ⋮ → Пользователи и добавьте пользователя: логин и пароль учётной записи ОС, под которой робот будет работать, и разрешение экрана. Для Windows это RDP-пользователь, для Linux — пользователь графического сеанса. пользователь появился в списке пользователей машины
  4. Робот. Роботы → Все роботы → Добавить робота: имя, машина и пользователь из предыдущего шага; остальные поля допускается оставить без изменений. После сохранения робот автоматически разворачивается на машине. в колонке Статус развертывания — «Выполнено»
Не видно раздела «Дистрибутивы робота»

Раздел отображается только в тенанте по умолчанию. Переключитесь на этот тенант.

Робот развёрнут. Выполнение проектов проверяется на следующем этапе.

Возможные проблемы

Машина добавлена, но в колонке «Доступна» пусто

Агент недоступен для Оркестратора. Проверьте адрес машины, порт агента и совпадение времени на серверах. → Робот не запускается

«Нет валидной лицензии»

Лицензия не загружена, истекла или выдана на другой Оркестратор. → Проблемы с лицензией
