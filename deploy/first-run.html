Первый запуск

Применимо: 1.26.9WindowsLinuxDocker

После установки Оркестратор ещё не готов к работе: нужны лицензии, дистрибутив робота и зарегистрированные машины. Здесь — путь от первого входа до тестового запуска робота в UI4.

Что нужно

  • Оркестратор установлен, UI открывается по https://<адрес>:44392.
  • Хотя бы на одной машине робота установлен агент (Машины роботов и агент).
  • Дистрибутив робота и тестовый RPA-проект.

Шаги

  1. Вход. Войдите встроенной учётной записью admin и смените её пароль. открылась главная страница UI4
  2. Запрос лицензии. Откройте Настройки → Лицензии, нажмите Запрос на лицензию, укажите Продукт и Количество. Сохраните запрос в текстовый файл и отправьте вендору. Запрос привязан к этому Оркестратору: для каждого Оркестратора — свой запрос. появилось сообщение «Запрос на лицензию успешно сформирован»
  3. Установка лицензии. Получив от вендора файл *.license, нажмите Добавить лицензию, выберите Файл и нажмите Загрузить. лицензия есть в списке, в колонках Состояние и Дата истечения — действующая лицензия; сообщение «Лицензия успешно добавлена»
  4. Дистрибутив робота. Откройте Настройки → Система → Дистрибутивы робота, нажмите Добавить дистрибутив Робота, выберите файл и сохраните. Отметьте нужный дистрибутив По умолчанию — он применяется при развертывании, если версия не указана. дистрибутив есть в списке, в колонке Наличие в хранилище он подтверждён
  5. Регистрация машины. Настройки → Система → Машины роботов → Добавить машину: Наименование, IP/DNS, для Linux — переключатель Linux. в колонке Доступна есть дата проверки, видна Версия агента
  6. Робот. Откройте Роботы → Все роботы, нажмите Добавить робота: Наименование робота, Машина робота, пользователь (для Windows — RDP-пользователь, для Linux — Пользователь графического интерфейса). сообщение «Робот успешно создан»
  7. Развертывание. У робота выберите действие Развертывание. сообщение «Процесс развертывания запущен», затем у робота нет подсказки «Робот не развёрнут — выполните развёртывание»
  8. RPA-проект. RPA-проекты → Все RPA-проекты → Добавить RPA-проект, загрузите тестовый проект. Затем Добавить робота к проекту. робот привязан к проекту
  9. Тестовый запуск. Нажмите Запустить проект. сообщение «Проект успешно запущен»; событие запуска видно в Журналы → События оркестратора, журнал робота — по действию Журнал

Пока нет ни одного дистрибутива робота, UI4 не даст добавить робота и предложит перейти в раздел дистрибутивов («Нет доступных дистрибутивов»).

Точное расположение кнопок «Развертывание», «Добавить робота к проекту», «Запустить проект» (меню действий строки, карточка) проверить на стенде и приложить скриншоты. Подписи взяты из i18n UI4 дословно.

Вкладки «Дистрибутивы робота» и «Дистрибутивы агента» показываются только в тенанте по умолчанию (условие isDefaultTenant) — проверить и отметить в тексте.
