Выбор варианта развертывания

Применимо: 1.26.9WindowsLinuxDocker

На странице описан выбор способа установки, СУБД и числа серверов. Выбранные значения запишите в лист планирования.

Как выбрать

  • Нужен быстрый стенд или пилот на Linux — Docker.
  • Linux-сервер без Docker (Astra, Ubuntu, РЕД ОС) — службы Linux.
  • Windows-сервер — службы Windows. Вариант с IIS не поддерживается.

Поставка рассчитана на один сервер — начинайте с него, если нет отдельных требований к отказоустойчивости.

Что входит в поставку каждого варианта и где это скачать — Дистрибутивы.

Во всех вариантах снаружи открыт один адрес — nginx на порту 44392 по HTTPS. Остальные службы видны только nginx и друг другу. Подробно — Порты и сетевой трафик.

СУБД

PostgreSQL подходит для всех вариантов. MS SQL Server — только если службы установлены на Windows Server; на Linux и в Docker — только PostgreSQL.

Один сервер или несколько

  • Один сервер. Конфигурация из поставки: все службы на одной машине. Начальный вариант установки.
  • RDP2 на отдельной машине. Подходит, если роботов на Windows много: RDP-сессии занимают память и процессор. Расчёт — в Требованиях к железу.
  • Несколько узлов. Требуются для отказоустойчивости. Распределение служб и изменения в конфигах — Масштабирование и отказоустойчивость.
