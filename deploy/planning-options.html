Выбор варианта развертывания

Применимо: 1.26.9WindowsLinuxDocker

Здесь вы выберете способ установки, СУБД и число серверов: какие варианты поддерживает поставка 1.26.9 и чем они отличаются.

Варианты

ВариантЧто в поставкеОсобенности
Docker ComposeФайл docker-compose.yml, образы служб на базе ubuntu:24.04, nginx.conf, сертификат cert1.crt/cert1.rsaВ compose уже есть PostgreSQL 14 и RabbitMQ 3. Файлы хранятся в томах Docker. RDP2 в compose нет — ставится отдельно.
Службы Linux (systemd)Архивы *-linux.zip с файлами юнитов; конфиг nginx.linux.conf и юнит Primo.Orchestrator.Nginx.serviceКаждая служба — в /opt/Primo/<Имя>. Для каждой есть два юнита: системный (от root) и пользовательский (systemctl --user, не от root).
Службы Windows + nginxАрхивы без суффикса, nginx.win.confСлужбы работают как службы Windows. nginx раздаёт UI и проксирует запросы.

Во всех вариантах снаружи открыт один адрес — nginx на порту 44392 по HTTPS. Остальные службы слушают HTTP на своих портах и видны только nginx и друг другу. Подробно — Порты и сетевой трафик.

СУБД

В решении есть миграции для PostgreSQL и для MS SQL Server — поддерживаются обе. Тип задаётся параметром DBVendor (по умолчанию Postgres). Docker-образы настроены только на PostgreSQL.

Один сервер или несколько

Конфиги nginx в поставке рассчитаны на один сервер: все службы указаны как 127.0.0.1:<порт>. Чтобы разнести службы:

  • в nginx.conf поменяйте адреса в блоках upstream;
  • в службах поменяйте адреса зависимостей: RabbitMQ:Host, DbConnection:Items:<БД>:Hostname, Orchestrator:BaseUrl (адрес WebApi), в WebApi — License:MachineInfoUrl и RobotLogs:BaseUrl.

RDP2 удобно ставить на отдельную машину: в Docker-конфиге nginx его адрес задаётся явно, потому что RDP2 работает вне compose.

Как выбрать

  • Нужен быстрый стенд или пилот на Linux — Docker.
  • Linux-сервер без Docker (Astra, Ubuntu, РЕД ОС) — службы Linux.
  • Windows-сервер — службы Windows с nginx. Вариант с IIS не поддерживается.

Требования к железусколько ресурсов нужно под выбранный вариант

Образы на базе Astra Linux (docker/astra/) в выгрузке есть, но конвейер сборки сейчас собирает только ubuntu-вариант (BASE_IMAGE: ubuntu, выбор astra закомментирован), а в astra-compose нет служб Queues и Licenses — уточнить, поставляется ли Docker на Astra в 1.26.9.

Kubernetes: в k8s/helm/ есть Helm-чарты, но они для внутреннего стенда разработки (тестовые адреса и значения). Поставки для Kubernetes заказчику в коде не найдено — не обещать в доках, пока не подтвердят.

Старое руководство 1.25.7 рекомендовало для Windows MS SQL, для Linux — PostgreSQL, и помечало PostgreSQL на Windows как «без гарантии поддержки». В коде это не отражено — сверить актуальную политику.
