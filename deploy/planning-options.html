Выбор варианта развертывания

Применимо: 1.26.9WindowsLinuxDocker

Страница поможет выбрать способ установки, СУБД и число серверов. Что выбрали — запишите в лист планирования.

Как выбрать

  • Нужен быстрый стенд или пилот на Linux — Docker.
  • Linux-сервер без Docker (Astra, Ubuntu, РЕД ОС) — службы Linux.
  • Windows-сервер — службы Windows. Вариант с IIS не поддерживается.

Поставка рассчитана на один сервер — с него и начинайте, если нет своих требований к отказоустойчивости.

Что входит в поставку каждого варианта и где это скачать — Дистрибутивы.

Во всех вариантах снаружи открыт один адрес — nginx на порту 44392 по HTTPS. Остальные службы видны только nginx и друг другу. Подробно — Порты и сетевой трафик.

СУБД

PostgreSQL подходит для всех вариантов. MS SQL Server — только если службы стоят на Windows Server; на Linux и в Docker — только PostgreSQL.

Один сервер или несколько

  • Один сервер. Конфигурация из поставки: все службы на одной машине. С неё начинают.
  • RDP2 на отдельной машине. Удобно, если роботов на Windows много: RDP-сессии занимают память и процессор. Расчёт — в Требованиях к железу.
  • Несколько узлов. Нужны для отказоустойчивости. Как разнести службы и что поменять в конфигах — Масштабирование и отказоустойчивость.

Требования к железусколько ресурсов нужно под выбранный вариант

Образы на базе Astra Linux (docker/astra/) в выгрузке есть, но конвейер сборки сейчас собирает только ubuntu-вариант (BASE_IMAGE: ubuntu, выбор astra закомментирован), а в astra-compose нет служб Queues и Licenses — уточнить, поставляется ли Docker на Astra в 1.26.9.

Kubernetes: в k8s/helm/ есть Helm-чарты, но они для внутреннего стенда разработки (тестовые адреса и значения). Поставки для Kubernetes заказчику в коде не найдено — не обещать в доках, пока не подтвердят.

Старое руководство 1.25.7 помечало PostgreSQL на Windows как «без гарантии поддержки» — уточнить, поддерживается ли он сейчас на Windows Server.

Строки «С чем придётся работать», «RDP2 — ставится как служба» и «Где лежат файлы» для Windows сформулированы по смыслу, по коду не сверены — проверить у разработки. Тип СУБД задаётся параметром DBVendor (по умолчанию Postgres) — со страницы планирования убран, есть в справочнике параметров.
