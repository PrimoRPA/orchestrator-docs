Роботы и машины

Применимо: 1.26.9WindowsLinuxDocker

Как добавить машину робота, пользователя сессии и робота, развернуть робота и понять его состояние.

Добавить робота

  1. Загрузите дистрибутив: Дистрибутивы робота → Добавить дистрибутив Робота. Отметьте По умолчанию — он применяется при развертывании, если версия не указана. В списке есть дистрибутив с нужной ОС и Разрядностью
  2. Добавьте машину: Машины роботов → Добавить машину, укажите Наименование и IP/DNS — по этому адресу Оркестратор обращается к агенту. В колонке Доступна — «Да», видна Версия агента
  3. Добавьте пользователя сессии: в строке машины Дополнительные действия → Пользователи. Для Windows — Добавить RDP-пользователя, для Linux — Добавить пользователя графического сеанса.
  4. Откройте Роботы → Все роботы → Добавить робота. Заполните Наименование робота, Машина, пользователя (поле называется RDP-пользователь или Пользователь графического интерфейса в зависимости от ОС машины), при необходимости Шаблон развертывания.
  5. Нажмите Развернуть (или Развернуть c параметрами, чтобы задать Разрядность, Порт, Язык, Версия ядра). Статус развертывания — «Развернут», Состояние робота — «Ожидает»

Поле Пользователь оркестратора: если пусто, робот входит в Оркестратор под встроенной учётной записью robot.

Если «Добавить робота» недоступно с подсказкой «Нет доступных дистрибутивов» — загрузите дистрибутив (шаг 1).

Состояния робота

В UI4Что значит
ОжидаетРобот развернут и свободен (RunStatus.Idle).
Выполняет проектИдёт проект (RunStatus.Running).
Стартует / Завершается работаПромежуточные состояния старта и остановки.
НедоступенРобот не присылал состояние дольше Robot:RunStatusTimeout (в классе опций — 30 с).

Статус развертывания: «Не развернут», «Развертывание», «Развернут», «Ошибка» (enum DeploymentStatus: Empty, Processing, Done, Error). Ход развертывания — в колонке Состояние: скачивание дистрибутива, распаковка, импорт ssl-сертификата, трансформация конфига, привязка сертификата.

Действия с машиной

  • Выключить — машина исключается из опроса состояния, предупреждения о её недоступности не пишутся в лог.
  • Пауза — начнётся, когда на машине не останется работающих оркестраторных роботов.
  • Работающие роботы (макс) — ограничение одновременно работающих роботов на машине.
  • Обновить выбранные — обновление агента из загруженного дистрибутива; ход виден по этапам («Скачивание AgentUpdater», «Остановка сервиса агента» …).
  • Перезагрузить — все запущенные процессы роботов будут прерваны.
