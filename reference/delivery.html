Применимо: 1.26.9WindowsLinuxDocker

Какие архивы и файлы собирает конвейер сборки Оркестратора 1.26.9 и что лежит внутри. Список составлен по сценариям сборки, а не по старому руководству: сторонние дистрибутивы (СУБД, RabbitMQ и т. п.) конвейер не собирает.

Находки по репозиторию — уточнить у разработки:

  • в 1.26.9/orchestrator/linux/ нет архива RobotLogs (в windows/ есть) — пропущен при выкладке?
  • архив webapi-iis по-прежнему выкладывается (1.26.7, 1.26.9), хотя вариант с IIS в документации не поддерживается;

Что внутри архива службы

  • Исполняемый файл Primo.Orchestrator.<Служба> и библиотеки, включая среду .NET.
  • appsettings.json и файл окружения: в Windows-архивах — appsettings.ProdWin.json, в Linux-архивах — appsettings.ProdLinux.json. appsettings.Development.json удаляется.
  • В Linux-архивах — файлы юнитов systemd Primo.Orchestrator.<Служба>.service и .user.service; из Windows-архивов они удаляются.
  • Version.txt с версией файла (FileVersion проекта, для WebApi — 1.26.9.0).

Имена архивов в репозитории

При выкладке в репозиторий артефактов имя приводится к виду primo-rpa-orchestrator-<компонент>-<версия>-windows.zip или …-linux.zip (например, primo-rpa-orchestrator-webapi-1.26.9.0-linux.zip). Без версии в имени архив выкладывается как <компонент>.zip в папки Windows и Linux.

Сравнение со старым руководством

Таблица «Дистрибутивы» в руководстве 1.25.7 (раздел «Комплект поставки») и файл LTools.Orchestrator.ComplectDescriber/Describe.json в коде 1.26.9 описывают комплект версии 1.25.1. Расхождения с конвейером 1.26.9:

  • Новые архивы, которых нет в старом списке: Licenses, Queues, ArcSight, отдельные AgentUpdater, PasswordEncryptor для Linux, DpaAgent и deb-пакеты DPA, Docker-образы и compose.
  • Конвейер не собирает и не выкладывает сторонние дистрибутивы из старого списка: PostgreSQL, TimescaleDB, MSSQL.zip, RabbitMQ, PowerShell 7.1.3, Chrome, Grafana и отчёты Report-*.zip, syncthing, logstash, haproxy, pg_cron, pg_ms.sh, RDP-Disconnector.xml, restore_console.bat, scr2.ps1, web.config, SQL-скрипты reset-ExchangeQueueStatistics-*.sql. Уточнить, собираются ли они в комплект вручную.
  • AgentInstaller.zip: проекта LTools.Orchestrator.AgentInstaller в решении 1.26.9 нет, конвейер его не собирает. Скрипт PrimoWorker.ps1 лежит в проекте агента.
  • Архив nginx: вместо nginx-1.21.1.zip/nginx-linux.zip выкладываются конфиги и сертификат из папки nginx; бинарного nginx в конвейере нет.
  • Документация из старой таблицы 2 (руководства под CentOS 8, Windows 2016) конвейером не формируется.
