Глоссарий

Применимо: 1.26.9WindowsLinuxDocker

Термины интерфейса UI4 и бэкенда Оркестратора. Слева — как термин подписан в UI4 (или как называется в документации), справа — имя сущности в коде: оно встречается в API, журналах и таблицах БД.

Объекты Оркестратора

ТерминОпределениеВ коде
АгентСлужба на машине робота: разворачивает и запускает роботов, держит RDP-сессии, выполняет команды WebApi. Обновляется через AgentUpdater.Agent, LTools.Orchestrator.Agent
Дистрибутив агентаЗагруженная в Оркестратор версия агента для обновления на машинах роботов. Раздел UI4 «Дистрибутивы агента».AgentDistr
Дистрибутив роботаЗагруженная версия робота, из которой агент разворачивает роботов. Дистрибутив по умолчанию применяется, если версия не указана.RobotDistr
ЗаданиеЕдиница запуска: какой проект и на каких роботах запускать, с какими переменными и ограничениями. Раздел UI4 «Задания».Assignment
ЗапускОдин запуск RPA-проекта на роботе. Раздел UI4 «Запуски».RpaProjectLaunch
Клиентский роботРобот, которого запускает пользователь на своей машине (attended). Раздел UI4 «Клиентские роботы».Attended…
Код операцииИдентификатор операции (запуска), которым связаны события Оркестратора и журнал робота. По нему фильтруют журналы.OperationKey
Машина роботаКомпьютер, на котором установлен агент и работают роботы. Раздел UI4 «Машины роботов».Worker
НодаЭкземпляр WebApi в кластере. Ноды подтверждают наличие дистрибутивов и архивов проектов у себя.Node, …NodeConfirm
Оркестраторный роботРобот, которым управляет Оркестратор (развёртывание и запуск по заданиям). Раздел UI4 «Оркестраторные роботы».Robot
Очередь обмена даннымиОчередь для обмена данными между роботами; состоит из элементов со статусами, тегами и метаданными. Раздел UI4 «Очереди обмена данными».ExchangeQueue, ExchangeQueueValue
Очередь проектовПроекты, которые ждут подходящего свободного робота. В UI4 — снимок состояния; сама очередь по умолчанию работает в RabbitMQ.RpaProjectQueue
ПапкаВиртуальная папка для разграничения доступа к объектам. У каждого пользователя есть «Моя папка»; общие папки — отдельная реализация. Разделы UI4 «Папки», «Общие папки».Folder, Folder2
ПодпискаПодписка на почтовые уведомления по выбранным событиям и объектам (робот, проект, задание, машина). Раздел UI4 «Подписки».Subscription
Производственный календарьРабочие и выходные дни для расписаний. Можно вести несколько календарей на год.ProductionCalendar, ProductionCalendar2
РасписаниеРасписание запусков, к которому привязываются задания. Раздел UI4 «Расписания».Schedule
Ресурс (ассет)Глобальная переменная, которую роботы читают во время работы, в том числе учётные данные. Раздел UI4 «Ресурсы».Asset
РоботЭкземпляр робота, развёрнутый на машине. Выполняет RPA-проекты.Robot
Группа роботовПроизвольная группа роботов, например для выбора роботов в задании.RobotGroup
RPA-проектПроект из Студии, загруженный в Оркестратор. У проекта есть технические версии v0…vN и версия разработчика.RpaProjectArchive, RpaProject
Стратегия очереди проектовСпособ обработки очереди проектов для тенанта. Раздел UI4 «Стратегия очереди проектов».RpaProjectQueueProcessingType
ТенантИзолированная область данных и пользователей в одном Оркестраторе. Тенант выбирается при входе (заголовок tenantId). Есть тенант по умолчанию, его можно отключить.Tenant
ТриггерУсловие запуска задания. Типы в UI4: «Запуск по расписанию», «Запуск при получении Email», «Запуск при изменении папки», «Запуск при завершении проекта Роботом», «Запуск из другого робота», «Запуск при наличии новых элементов в очереди обмена данными», «Остановка по таймауту».Trigger, TriggerType
Шаблон развертыванияНабор параметров запуска робота (журналирование, число потоков, приоритеты, отладка), который назначается роботам. Раздел UI4 «Шаблоны развертывания».DeployTemplate

Администрирование и безопасность

ТерминОпределениеВ коде

Квота на лицензии роботаОграничение числа лицензий робота для пользователя.UserRobotQuota
Способ входаОркестратор (локальные учётные записи), LDAP, Negotiate (Kerberos SSO), Keycloak — задаётся Auth:Type.AuthType
Контроль целостности конфигурацииОркестратор хранит хэш конфига и фиксирует изменения с прошлого запуска.ConfigHash, ConfigService
