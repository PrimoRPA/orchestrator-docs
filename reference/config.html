Параметры конфигурации

Применимо: 1.26.9WindowsLinuxDocker

Параметры всех служб Оркестратора: имя ключа, тип, назначение и значение по умолчанию. Таблицы собраны из классов опций и прямых чтений конфигурации в коде версии 1.26.9. Если ключа нет в файле службы, действует значение из колонки «По умолчанию».

Где задаются параметры

Каждая служба при старте собирает конфигурацию из источников ниже. Источник ниже по списку перекрывает вышестоящий.

  1. appsettings.json в папке службы.
  2. appsettings.{ASPNETCORE_ENVIRONMENT}.json там же.
  3. Аргументы командной строки (у всех служб, кроме RDP2).
  4. Переменные окружения. Вложенный ключ записывается через двойное подчёркивание: RabbitMQ__Host для RabbitMQ:Host.

Переменная окружения ASPNETCORE_ENVIRONMENT обязательна: без неё служба пишет «Environment variable 'ASPNETCORE_ENVIRONMENT' not set. Aborting.» и не запускается.

В таблицах ниже ключ записан через двоеточие: Секция:Ключ. В JSON это вложенные объекты. [n] обозначает элемент массива, <имя> — ключ словаря, который вы задаёте сами.

Пароли в конфиге (RabbitMQ, строки подключения, AD, MinIO и т. п.) службы ожидают в зашифрованном виде, если не используется Vault. Алгоритм задаёт ConfigPasswordEncryptor:Algorithm: RSA или AES; пусто — AES.

Службы: WebApi · Агент · RDP2 · RobotLogs · States · Notifications · Analytic · Licenses · Queues · MachineInfo · LogEventsWebhook · DpaAgent · ArcSight

Внешнее хранилище секретов

Ключ Secrets:External включает хранилище секретов: DB (отдельная БД секретов, устаревший вариант) или Vault. Старое булево значение true служба понимает как DB и пишет предупреждение в журнал.

Для Vault адрес и учётные данные берутся из переменных окружения: VAULT_URL, VAULT_TOKEN или VAULT_USER_NAME + VAULT_PASSWORD, VAULT_PATH, VAULT_MOUNT_POINT. Если переменной без префикса нет, служба ищет её с префиксом своего имени: WEBAPI_, ROBOTLOGS_, STATES_, NOTIFICATIONS_, ANALYTIC_, LICENSES_, QUEUES_, LOGEVENTSWEBHOOK_, AGENT_.

Подключение к PostgreSQL через DbConnection

Вместо строк ConnectionStrings для PostgreSQL можно задать параметры по полям в DbConnection:Items. Если секция пуста, используются ConnectionStrings. Имена элементов фиксированы:

  • WebApi: Default, Identity, License, ProcessRepository;
  • RobotLogs: Logs;
  • Analytic: Analytic;
  • Licenses: Licenses.

Поля элемента — в таблице DbConnection выше. Для MSSQL секция не используется.

Что сверить

Расхождения значений по умолчанию внутри кода. Класс опций задаёт одно, а при регистрации служб в Startup.cs ключ читается напрямую с другим значением. Пока ключ не задан в конфиге, работает значение из Startup:

  • RDP:EnabledLogOffDisconnectedRDPUsers: в классе true, в Startup — false. Без явного ключа служба разлогинивания не регистрируется.
  • RDP:LogOffDisconnectedRDPUsersService: в классе Opt2, в Startup — Legacy.
  • Secrets:PasswordEncripted, Secrets:ConnectionPasswordEncripted (WebApi): в классе true, в Startup — false.
  • Secrets:External в классах опций RobotLogs, Analytic, Licenses, Queues, LogEventsWebhook объявлен как bool, а Startup этих служб читает его как перечисление DB/Vault.

В старом руководстве (1.25.7, «Открытие/отключение/разлогинивание RDP-сессий») RDPSessionsReleaseService и LogOffDisconnectedRDPUsersService названы «системными, будут удалены». В 1.26.9 они по-прежнему выбирают реализацию служб.

Нет назначения в коде: IsMultiMaster (уточнить сценарий), Robot:RequestTimeoutSec в WebApi (значения по умолчанию нет: без ключа читается 0, а нулевой таймаут HTTP-клиент .NET не принимает — проверить, нужен ли ключ в поставляемом конфиге), Observability:Unloading:Items:<имя>:ObjectFlow, CustomerBinding:Key (MachineInfo).

В Docker-образах (k8s/*.Dockerfile) задан Security__Jwt__SessionLifetimeTailMin=60, но в коде 1.26.9 этот ключ не читается. Там же Security__Jwt__SessionLifetimeMin=720 — в коде значения по умолчанию у этого ключа нет.

Не вошли в таблицы: внутренние файлы параметров агента (RunnerOptions, AgentUpdaterOptions), которые агент сам пишет при запуске робота в Linux и при обновлении. Также не вошли служебные утилиты из поставки (ComplectDescriber, BluePrismConverter, WinClient, RobotMock).
