Жизненный цикл версий и LTS

Применимо: 1.26.91.26.7 LTS1.25.7 LTS

Как читать номер версии Оркестратора, как часто выходят релизы и что такое LTS. Номер версии важен и для лицензии: от него зависит, можно ли обновиться по бессрочной лицензии.

Номер версии

Серверные службы и агент нумеруются как 1.ГГ.М.П:

ЧастьЗначениеПример для 1.26.9.0
1линейка продукта1
ГГгод выпуска (20ГГ)2026
Ммесяц выпускасентябрь
Пномер патча внутри релиза0

Так номер трактует и проверка лицензии в WebApi: версия 1.ГГ.М считается выпущенной 1-го числа месяца М года 20ГГ. Кроме номера у сборки есть информационная версия с номером сборки, например 1.26.9.0+25383.

UI4 нумеруется отдельно: 4.ГГ.М.П (с 4.26.6.0; раньше — 4.0.0…4.4.0, а UI2 — 2.x). В релиз 1.26.9 входит UI4 4.26.9.1.

Ветки релизов

Каждый релиз собирается из своей ветки: бэкенд — releases/v1.26.9.0, UI4 — releases/v4.26.9.1. Патчи релиза выходят с увеличением последней цифры (в Readme служб встречаются, например, 1.25.7.47 и 1.26.7.2).

Частота выпусков

По Readme служб в 2025 году выходили версии 1.25.1, 1.25.3, 1.25.5, 1.25.7, 1.25.9, 1.25.11 — раз в два месяца. В 2026 году после 1.26.1 и 1.26.3 релизы идут каждый месяц: 1.26.4 … 1.26.9.

LTS

LTS — версия с долгой поддержкой, на которую переносятся исправления в виде патчей 1.ГГ.М.П. Действующие LTS: 1.25.7 и 1.26.7. В Readme WebApi так же помечена предыдущая LTS — 1.24.6.0.

Версия и бессрочная лицензия

Для бессрочной лицензии Оркестратора WebApi при пересчёте лицензий сравнивает дату своей версии с датой начала лицензии:

  • в первый год (365 дней, с поправкой на високосный) действия лицензии допустима любая версия;
  • после этого допустимы только версии, «выпущенные» раньше, чем через год от начала лицензии.

Пример из кода: лицензия с 01.10.2024 допускает версии до 1.25.9 включительно; на 1.25.10 и новее лицензия станет невалидной с причиной «обновление на недопустимую версию». Проверяйте это до обновления — см. Перед обновлением.

Статус LTS для 1.25.7 и 1.26.7 в коде не зафиксирован: в Readme помечена только 1.24.6.0 (LTS). Подтвердить по вики продукта («Текущие LTS, ветки и порядок портирования») и указать имена LTS-веток.

Сроки поддержки LTS и обычных релизов (сколько месяцев выходят патчи, когда версия снимается с поддержки) в коде и старых доках не найдены.

Соответствие версий UI4 и бэкенда для LTS-линий (например, какой UI4 идёт с 1.25.7.x и 1.26.7.x) не проверено. В CHANGELOG UI4 упоминается LTS-линия UI 4.0.x.

Месяц в примере (1.26.9 — сентябрь 2026) выведен из правила нумерации в LicenseService; дату выхода релиза сверить с релиз-ноутами.
