Порты

Применимо: 1.26.9WindowsLinuxDocker

Порты служб Оркестратора и внешних компонентов: кто слушает, по какому протоколу и кто подключается. Значения взяты из конфигов nginx, Dockerfile, шаблона docker-compose и кода.

Порт службы задаётся адресом точки Kestrel: Kestrel:EndPoints:InternalHttp:Url (HTTP) или Kestrel:EndPoints:ExternalHttps:Url (HTTPS). Номера ниже — те, на которые настроены поставляемые nginx-конфиги и Docker-образы для Ubuntu. Если вы меняете порт службы, поменяйте и upstream в nginx.

Порты 5001, 56748, 5088, 5089, 8081, 5102, 5080 и 3000 (Grafana) взяты из upstream nginx-конфигов; 5051, 56749, 56750, 56751, 56770 — из Docker-образов для Ubuntu. У каждой службы есть проверки /health, /health/readiness, /health/liveness.

Docker-образы на базе Astra Linux и образы из k8s/*.Dockerfile слушают внутри контейнера порт 8080 (метрики — 10052), а не номера из таблицы.

Docker-образ LogEventsWebhook для Astra (docker/astra/log-events-webhook.Dockerfile) и k8s/log-events-webhook.Dockerfile задают Kestrel__EndPoints__InternalHttp__Url=http://*:80, а объявляют EXPOSE 8080. Проверить на стенде, на каком порту служба реально слушает.

Расхождения со старой статьёй «Сетевые порты» (раздел для системного администратора): диапазон 8000–9000 «для роботов» в 1.26.9 не используется — параметры RobotDeployment:PortMin/PortMax помечены в коде как неиспользуемые новыми версиями робота. Порт 3389 там приписан RDP2, но по коду RDP2 сам подключается к машинам роботов по 3389, а слушает 5102. В старой таблице нет портов RobotLogs, Queues, Licenses, NuGet2, RDP2, метрик и RabbitMQ Management.

LDAP/LDAPS (389/636) и SMTP 465 из старой статьи в коде как значения по умолчанию не заданы: порт LDAP задаётся адресом контроллера в ActiveDirectory:MultyForest, SMTP — Email:FromSmtpPort.

Порт MS SQL Server и порты Redis, Vault, MQTT в коде не заданы: они берутся из строк подключения и адресов в конфиге.

Путь, по которому служба отдаёт метрики Prometheus, в коде явно не задан (используется KestrelMetricServer с настройками по умолчанию) — сверить на стенде.
