Порты

Применимо: 1.26.9WindowsLinuxDocker

Порты служб Оркестратора и внешних компонентов: кто слушает, по какому протоколу и кто подключается. Значения взяты из конфигов nginx, Dockerfile, шаблона docker-compose и кода.

Порт службы задаётся адресом точки Kestrel: Kestrel:EndPoints:InternalHttp:Url (HTTP) или Kestrel:EndPoints:ExternalHttps:Url (HTTPS). Номера ниже — те, на которые настроены поставляемые nginx-конфиги и Docker-образы для Ubuntu. При изменении порта службы измените и upstream в nginx.

Порты 5001, 56748, 5088, 5089, 8081, 5102, 5080 и 3000 (Grafana) взяты из upstream nginx-конфигов; 5051, 56749, 56750, 56751, 56770 — из Docker-образов для Ubuntu. У каждой службы есть проверки /health, /health/readiness, /health/liveness.

Docker-образы на базе Astra Linux и образы из k8s/*.Dockerfile слушают внутри контейнера порт 8080 (метрики — 10052), а не номера из таблицы.
