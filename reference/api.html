API

Применимо: 1.26.9WindowsLinuxDocker

Адрес Swagger, получение токена и группы методов WebApi. Полный список методов с параметрами приведён в Swagger установки.

API Оркестратора не публичный. Swagger есть в каждой установке, но обязательств по обратной совместимости API нет: методы и их параметры могут меняться от версии к версии. Подробное описание API выдаётся по запросу.

Swagger

Swagger включён во всех службах, кроме NuGet2, независимо от окружения: в Startup.cs каждой службы AddSwagger вызывается без условий, отдельного параметра для отключения нет. Пути одинаковые:

ЧтоПуть
Интерфейс Swagger UI/api/doc
Описание OpenAPI (JSON)/api/v1/swagger.json
Запрос к /apiперенаправление (301) на /api/v1/swagger.json

Для WebApi через nginx: https://<сервер>:44392/api/doc — путь /api/ проксируется в WebApi. Swagger остальных служб открывается напрямую на порту службы (см. «Порты»), например http://<сервер>:56748/api/doc для RobotLogs.

В Swagger WebApi, RobotLogs, Licenses, Queues, Analytic, RDP2 и агента есть кнопка ввода токена (схема Bearer). Значение вводится целиком: Bearer <токен>.

Аутентификация

API защищено JWT-токенами (схема Bearer). Токен подписывает WebApi; издатель, аудиторию и ключ подписи задают переменные окружения PRIMOISSUER, PRIMOAUDIENCE, PRIMOSIGNINGKEY (см. «Параметры конфигурации»). Время жизни — Security:Jwt:SessionLifetimeMin.

  1. Отправьте POST /api/Account с телом {"userName": "…", "password": "…"}. Для тенанта передайте заголовок tenantId. В ответе есть поле token.
  2. Передавайте токен в каждом запросе: заголовок Authorization: Bearer <токен>. Защищённые методы отвечают не 401.

Другие способы входа в AccountController:

МетодДля чего
POST /api/Account/{ad}Вход логином и паролем домена AD (LDAP).
GET /api/Account/LoginNegotiateВход по Kerberos (SSO), в том числе для роботов и Студии.
POST /api/Account/KeyCloak1/LoginВход через Keycloak, простой поток.
GET /api/Account/KeyCloak2/AuthUrl, /KeyCloak2/Login, /KeyCloak2/Token/{state}Вход через Keycloak с PKCE.
POST /api/Account/AttendedRobot, GET /api/Account/AttendedRobotLoginNegotiateВход attended-робота.
POST /api/Account/logoutВыход.

Разрешённые способы входа задаёт Auth:Type. Доступ к методам проверяется по разрешениям ролей пользователя. Для веб-сокета (SignalR, путь WS:Path, по умолчанию /events) токен можно передать в строке запроса access_token.

Группы методов WebApi

Все контроллеры WebApi доступны по пути /api/<Контроллер>. Отметка «без входа» — в контроллере есть методы, доступные без токена.
