После встречи с техписателями, поддержкой и продуктом

  • «Начало работы» — маршрут «кому какой раздел» и «Как устроен Оркестратор». Основные понятия, совместимость и жизненный цикл версий — в Справочнике.
  • Установка — одна страница, ОС на вкладках (Docker, Astra Linux, РЕД ОС, Ubuntu, Windows Server): на вкладке весь путь сверху вниз, в меню один пункт. Выбор запоминается, ссылка вида install.html#astra открывает нужную вкладку.
  • Вариант «Windows + IIS» убран: на Windows службы ставятся службами Windows, UI4 публикует nginx.
  • Установка агента — вкладки Windows и Linux, нужная открывается сама по ОС из браузера.
  • MQTT убран из обязательных компонентов: по коду это необязательный режим связи WebApi и RDP2 в 1.26.8–1.26.11, по умолчанию — REST; в ветке следующей версии MQTT удалён.
  • Службы Linux без root — целевая схема, отдельная страница; от root — альтернатива.
  • «Машины роботов и агент» — внутри «Установки».
  • Требования к железу — с явным предупреждением: это минимум, реальные цифры зависят от нагрузки.
  • Порядок разделов: Развертывание → Настройка → Обновление.
  • Обновление начинается с проверки лицензии и бэкапа; порядок и шаги по платформам — на одной странице; изменения конфигов — по конкретным LTS.
  • Неполадки пересобраны по частым обращениям в поддержку: 12 симптомов вместо 6 — задания и триггеры, почта, очередь проектов, зависание запуска, остановка робота, RDP, пустой журнал, лицензия, интерфейс, медленная работа, вход, права.
  • Совместимость: матрица «продукт × продукт» по LTS; ограничение версии Студии вынесено отдельно — это настройка, а не совместимость.
  • Справочник: страница MCP Server; пометка, что API не публичный; публикацию структуры БД — согласовать.
  • Архив UI2 убран: остаётся в документации старых версий.
  • Правила наполнения дополнены: пересчитывать перечисления, заглушки под скриншоты, установку писать под последний LTS.
  • Найдено в коде при сверке:
    • бессрочная лицензия старше года может стать невалидной после обновления с 1.25.7 LTS — проверка версии стала строже с 1.26.4;
    • часть параметров из патчей LTS (например, часовой пояс планировщика) отсутствует в 1.26.9;
    • в Docker с 1.26.7 LTS файлы хранятся не в MinIO, а на томах — данные сами не переедут;
    • на Linux все службы, nginx и агент умеют работать без root;
    • агент сам подставляет команду графического сеанса для Astra, РЕД ОС и CentOS — вручную нужно только для Ubuntu.
  • Эта страница истории; сама документация — по кнопке выше.
